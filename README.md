## Tabbybyte Technologies Landing Page

This is a static landing page for Tabbybyte Technologies, ready for deployment on GitHub Pages.

### How to Deploy

1. Push all files (`index.html`, `logo.png`, etc.) to your repository's `main` or `gh-pages` branch.
2. In your repository settings, enable GitHub Pages and set the source to the root of the branch.
3. (Optional) If you have a custom domain, add a `CNAME` file with your domain name.

### Notes
- The `<base href="./">` tag ensures all assets load correctly on GitHub Pages.
- Your favicon and logo will work as long as `logo.png` is in the root with `index.html`.
